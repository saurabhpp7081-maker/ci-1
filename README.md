## 📦 Installation

### 1. Clone Repository

```bash
git clone https://github.com/SAURABHPP7081/ci-1.git
```

### 2. Move Project

Copy the project into your local server.

Example:

```
htdocs/
```

or

```
www/
```

---

### 3. Create Database

Create a new MySQL database.

---

### 4. Configure Database

Open

```
application/config/database.php
```

Update

```php
$db['default'] = array(
    'hostname' => 'localhost',
    'username' => 'root',
    'password' => '',
    'database' => 'your_database',
);
```

---

### 5. Configure Base URL

Open

```
application/config/config.php
```

Update

```php
$config['base_url'] = 'http://localhost/ci-1/';
```

---

### 6. Run Project

Open your browser

```
http://localhost/ci-1
```
